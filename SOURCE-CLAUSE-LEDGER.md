# PEACHES source-to-clause ledger

This ledger is a preparation and provenance record. `SOURCE_DERIVED`
identifies a rule observed in a named source. `ENGINEERING_CHOICE` identifies
an implementation choice. `BRANCHLINE_SPECIFICATION` identifies a choice made
for [PEACHES Floor v1](FLOOR.md). `SUPERSEDED_EXPERIMENT_PROPOSAL` preserves a
discarded checker-centered proposal. No row adopts a source, proves source
conformance, creates Genesis, or issues a stamp. The exact current boundary is
[PREGENESIS-FREEZE.md](PREGENESIS-FREEZE.md).

## Mapping rule

The source package is a reference corpus, not an authority stack. Where a
Branchline clause differs from a source, the ledger labels the difference.
Where a source version is not current, the ledger preserves that fact and
carries a compatibility residual rather than silently relabeling it. The
current floor is defined only by `FLOOR.md`; the SQLite/checker chain remains a
separate, nonnormative Branchline experiment.
