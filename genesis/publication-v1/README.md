# Publication receipt

The [signed records](../signed-v1/README.md) were published at commit
[`ad16ad6a72c4b3b76595d609cbfb1fb9fcac8d0d`](https://github.com/Grativy6/book-of-peaches/commit/ad16ad6a72c4b3b76595d609cbfb1fb9fcac8d0d).
The commit was then fetched from the public GitHub repository. Every original
bundle member and the ZIP matched the upload byte for byte, and both retrieved
signed envelopes passed the frozen checker with its pinned dependency.

[github-publication-receipt.json](github-publication-receipt.json) preserves
the commit, tree, exact envelope hashes, stamp IDs, verification results, and
content-addressed [publication method](../signed-v1/github-publication-method.md).
This successor record avoids placing a commit's own identifier inside itself.

The receipt is an unsigned assistant retrieval report, not a Floor observation
or an independent timestamp witness. Its local observation time is explicitly
a claim. Public content anchoring is recorded; an independently authenticated
time bound remains open. Further evidence can be appended without changing
the signed records or erasing this publication trace.
